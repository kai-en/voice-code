# M6.1 voice-end 退出工具插件设计 2026-09-25

目标：让 oc2（opencode v2.0.16）的 LLM 能主动调用 `voice-end` 工具结束语音会话；编排器（M5，暂缓）从 SSE 事件感知。依据 deepthink 调研（v2.0.16 源码+文档双源，2026-09-25）。

## 0. 可行性结论

可行，官方一等公民机制（`ctx.tool.transform`+`editor.add`→native tools 下发），v2 无现成等价物（内置 question/generateObject/terminate 均不适用，证据见调研报告）。唯一真实风险=小模型不调/乱调（无 tool_choice 强制口），误触代价可控。

## 2. 插件语义（handler 返回值设计）

- description 写死 ONLY 条件（用户道别/明确要求结束时才调）+ 调用后说一句短告别。
- execute 返回：`"Voice session is ending. Say one short friendly goodbye now, then stop. Do not call any tools."`
- 时序：called→模型自然续一步产出告别语→`session.text.*`→`execution.succeeded`（TurnDone）。**消费方不掐断**，等 TurnDone 播完再见再关会话——零额外机制。

## 3. 验证步骤（人审 T-M6.1-x）

1. 放 voice-end.ts + AGENTS.md → `scripts/m6_e2e.py` 同款方式起服，确认 SSE 出 `plugin.updated` 帧（加载证据；失败看 server 日志 `Skipping invalid tool registration`）。
2. **T-M6.1-1 正例**：挂 /api/event 监听→prompt"用一句话跟我道别，然后结束本次会话"→期望帧链 `tool.input.started(name==voice-end) → input.ended → called(同 id) → success(=handler 文本) → text.delta/ended(告别语) → execution.succeeded`；由 M6 单测外的真机脚本 `human-test/m61_voice_end_plugin.py` 自动比对并回报。
3. **T-M6.1-2 反例**：prompt"今天天气怎么样"→无 voice-end 的 called 帧、正常回答。
4. 免费池抖动：正例若 3 连败（小模型不调工具）→ 记录并回报，调 description/AGENTS.md 措辞再试；仍败则本包状态回退"有条件可行"。

## 4. 风险

中：小模型触发不稳（无强制口；缓解=ONLY 措辞+AGENTS 规则+T-M6.1-1 连测）。低：bun 二进制 import 解析不确定（零 import 写法已规避）；文档站超前 2.0.16（以源码路径为准，自动发现目录无 config plugins 字段的"必须是目录"坑）。

## 5. 与 M5 的接缝（预记，M5 设计届时引用）

M5 收 `OcTool(name=="voice-end", phase=="called")` → 置 pending_exit；TurnDone 到达→播告别→sid=None→IDLE。不进 hub（hub 保持零业务）。
