## TL;DR（口播底稿）
随机团的锁定是**每个BOSS每周只有一次拾取**：不管出没出装备，第一次击杀就消耗掉拾取资格；本周再排同一个BOSS能进能打完，但**不会再有掉落**，等于帮别人打。锁按周重置，国服是**每周四**（和宏伟宝库、周常一起刷）。重复打没有额外收益，收益只在"本周还没拾取过的其他BOSS"上。

## 方向性声明
- 作用于谁：**按角色**计的拾取资格锁定——同战网其他角色各算各的，小号可以再拾取同一BOSS。
- 在哪一侧生效：随机/普通/英雄难度的"每周一次拾取"（本条主口径 LFR）；锁的是**拾取资格**，不是进场资格，可随时重复排队重打。
- 不控制什么：**不控制史诗难度**——史诗团本锁的是**整个团队ID进度**（换ID才能重进；单首领巢穴类如孢陨幽境 M 不锁CD、可反复ROLL，见 retail.raids.lfr-sporefall-rotmire）；也不覆盖怀旧/classic 线条目；重置的**具体钟点**各稿冲突未钉死（见证据边界）。

## 机制细节
- 逐BOSS独立CD：分区之间互不影响，本周打过1区不挡你排2区；一个区内跳过的BOSS之后还能回头补。
- "没出装备也算已拾取"：个人拾取在击杀瞬间判定一次，没 roll 到不补机会（百度知道 2017 答案+NGA 楼主一致，B/C 旁证）。
- 重复打收益：无装备/无拾取窗口；宝库格数按本周击败的**首领个数**累计（S2 稿口径 2/4/6 个开三档团队格），同一BOSS重复杀**不叠加**（社区稿口径，游戏内为准）。
- 周节奏：国服每周四例行维护刷新随机团 CD、周常与宏伟宝库领取（5.3 起从周二改到周四并沿用；S2 分区解锁日程全落在周四佐证）。

## 常见误区
- "这周没出货，再排一次同一个BOSS还能 roll" → 不能，拾取资格一次击杀即消耗。
- "重复打能多攒宝库进度" → 宝库按不同首领个数计，同一BOSS只算一次。
- "团本CD锁把我关在外面" → 随机/普通/英雄只锁拾取不锁进场；**锁ID的是史诗难度**。
- 把国际服周二/周三维护当成国服时间 → 国服周四是周四；几点几分以当周维护公告和游戏内为准。
- 老团本/新赛季团本混排（233 vs 272/279）→ 见 lfr-s2-venomous-rewards 常见误区。

## 证据边界（红线6）
拾取锁定/CD重置是**服务端规则**，客户端 UI 镜像证明不了。本条结论=NGA 一手楼主正文（S 载体/B 性质）+ 2026 年 9-10 月两篇独立稿 + 官方日程周四日期 + 2013 公告转载，关键项（每BOSS每周一拾取/可重复打无拾取/周四刷新）逐项一致；**重置钟点**（3:00/4:00/7:00 诸稿互斥）按未核实处理，不入库不口播。
